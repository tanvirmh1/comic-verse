Place your existing cover.webp file in this folder.
Place chapter page images inside chapter-1 and name them page-1.webp, page-2.webp, page-3.webp, and so on.
The first page is currently connected in app.js. Add additional page image paths to the Eleceed chapterPages list there.
Other comic image folders are intentionally not supplied; their missing images will show the browser's broken-image icon.
